# 前端 MVP 开发状态与交接文档

**文档更新日期**: 2026-04-21
**当前阶段**: MVP (纯静态 Mock 数据演示版)

## 1. 技术栈与架构
本系统前端定位于轻量级工业数据展示面板，采用传统而稳定的技术栈，未引入复杂的构建工具（如 Webpack/Vite），适合快速迭代和与 Python 后端直接集成。

- **核心结构**: HTML5 + CSS3 + 原生 JavaScript
- **DOM 操作 & 工具**: jQuery 1.8.3
- **UI 框架**: Layui (经典模块化 UI，非常适合后台与工业数据看板)
- **图表库**: ECharts
- **数据来源**: 纯前端 Mock 数据 (`frontend/static/js/mock.js`)

## 2. 目录结构
```text
frontend/
├── index.html          # 主框架页面（左侧导航、顶部药丸按钮主题切换+系统时钟、多标签页+iframe 容器）
├── views/              # 各个子页面内容（通过 iframe 嵌入主框架）
│   ├── dashboard.html  # 调度概览（KPI卡片、仪表盘、柱状图、调度结果表、告警滚动）
│   ├── history.html    # 历史查询（日期筛选、下拉框、折线图、历史分页表格+状态徽章）
│   ├── workshops.html  # 车间管理（CRUD数据表格、新增弹窗、批量操作、启用状态开关）
│   └── settings.html   # 系统配置（可编辑表单，映射全部 WW_SYSTEM_CONFIG 配置项）
└── static/             # 静态资源目录
    ├── css/
    │   └── style.css   # 全局样式、明暗主题 CSS Variables、Layui 组件深度覆盖、状态徽章
    ├── js/
    │   ├── charts.js   # ECharts 图表初始化、数据挂载及主题自适应逻辑（Dashboard 专用）
    │   ├── main.js     # 框架层交互（系统时钟、菜单点击 iframe 切换、主题切换逻辑）
    │   └── mock.js     # 模拟后端 API 数据的生成工厂
    └── lib/            # 存放本地化的第三方依赖库 (layui/, jquery, echarts)
```

## 3. 已实现的核心功能

### 3.1 页面模块
- **调度概览 (Dashboard)**:
  - 核心数据 KPI 统计卡片 — 5等分布局（flexbox `kpi-row`/`kpi-col`），展示：当前储罐液位、系统状态、启用车间数、总建议排放速率、调度周期时间（当前周期 + 下期调度，30分钟对齐整点/半点）。
  - ECharts 仪表盘 (Gauge) 展示当前储罐液位及四级状态（正常/预警/告警/紧急），仪表盘下方含图例行说明液位区间与状态对应关系（正常<80%、预警80-90%、告警90-95%、紧急≥95%），图例颜色随主题切换同步更新。
  - ECharts 柱状图 (Bar) 对比各车间的最大排放能力与当前建议排放速率。
  - Layui 数据表格展示详细的建议排放分配方案，建议速率列以主题色高亮加粗显示。表格右上方"查看详情"链接，点击弹出本周期调度详情弹窗，与历史查询详情弹窗布局、样式、锚点导航完全一致。
  - 告警播报面板：标题"最近10条告警"，自动走马灯滚动（每秒滚动一条，距离为告警元素实际高度，`translateY` + 内容复制实现无缝循环），鼠标悬停暂停滚动；每条告警含时间（MM/DD HH:mm格式）、级别彩色标签（正常/预警/告警/紧急）、消息内容（含液位和占比数据）；固定高度300px，`overflow:hidden` 隐藏滚动条。
  - 同行卡片等高：`syncCardHeights()` JS 函数在表格渲染后（`setTimeout 300ms`）及窗口 resize 时执行，精确计算卡片几何关系同步等高——第二排仪表盘/柱状图等高+仪表盘图表自适应撑满，第三排表格/告警等高+告警容器自适应撑满。
- **历史查询 (History)**:
  - Layui 日期时间范围选择器 (`laydate`，暗色模式下使用 `molv` 主题) 与车间下拉筛选框。
  - ECharts 折线图 (Line) 展示实际液位与预测液位的历史趋势对比，支持主题色自适应。
  - 支持前端假数据分页的历史调度记录表格，状态列使用彩色柔和徽章区分（绿色 NORMAL / 黄色 WARNING / 红色 ALERT / 深红色 EMERGENCY）。
  - 行点击高亮：点击表格任意行即高亮当前行（添加 `layui-table-click` 类），与详情弹窗交互分离，详情需点击操作列按钮才弹出。
  - 详情弹窗完整展示调度快照：调度输入快照（3列网格，含储罐容量、处理能力、调度周期、安全容量系数、阈值、液位、弹性系数k、约束上限等15项参数）、车间配置快照表格、建议排放表格（含调度状态徽章）、求解过程（约束条件列表含公式说明与分步计算、车间满足状态、r_i分配说明）。
  - 详情弹窗浮动锚点导航：右侧固定导航菜单，支持平滑滚动定位、滚动高亮、点击跳转中间位置。
  - 详情弹窗暗色模式视觉层级：数据卡片使用 `rgba(255,255,255,0.04)` 背景 + `rgba(255,255,255,0.06)` 边框区分层次；锚点导航使用 `#25282C` 背景增强浮起感。
  - 详情弹窗模块标题颜色统一：浅色模式 `#10b981`，暗色模式 `#2ADB5C`，与全局主题色一致。
  - 告警记录悬浮提示：自定义 tooltip 样式（暗色圆角背景），告警消息不含冗余级别前缀。告警消息格式嵌入液位数据：`[区域] 原因（当前液位xxx m³，占比xx.x%）`。
- **车间管理 (Workshops)**:
  - Layui 数据表格展示车间列表，支持行内编辑（车间名称、最大/最小速率、权重、备注）。
  - 启用状态列使用 Layui Switch 开关组件，支持实时切换并显示反馈。
  - 新增车间弹窗（`layer.open`，含关闭按钮），包含完整的车间信息表单。
  - 批量更新、批量删除、单行更新/删除等操作按钮。
- **系统配置 (Settings)**:
  - 可编辑的 Layui 表单，展示并允许修改全部 10 个 `WW_SYSTEM_CONFIG` 核心调度参数：
    - TANK_CAPACITY（储罐容量）
    - PROCESS_CAPACITY（处理能力）
    - SCHEDULE_INTERVAL_MIN（调度周期）
    - MANUAL_LEVEL_STALE_THRESHOLD（液位超期阈值）
    - SAFE_RATIO（安全容量系数）
    - WARNING_RATIO（预警阈值）
    - ALERT_RATIO（告警阈值）
    - EMERGENCY_RATIO（紧急阈值）
    - MIN_RATE_RATIO（弹性压缩最低保留比例）
    - PROCESS_BUFFER_RATIO（处理能力缓冲系数）
  - 配置项 Label 等宽自适应：JS 动态测量最宽 label（"弹性压缩最低保留比例"），统一所有 label 宽度。
  - 按钮组位于表单顶部靠左对齐，提供"保存配置"和"重置"按钮。

### 3.2 高级 UI/UX 与主题自适应
采用现代化设计规范，浅色模式主色调为生态环保绿 `#10b981`，暗色模式为 `#2ADB5C`，系统实现了完善的明暗主题无缝切换：

- **CSS Variables 驱动**: 通过 `[data-theme="dark"]` 统一管理全局背景色、面板色、边框色与主副文本色。浅色模式重新定义了柔和的 Slate 系色板（`--bg-color: #f9fafb`、`--text-color: #334155`），暗色模式保持极简暗黑风格（`--bg-color: #090A0B`）。
- **多标签页架构**:
  - 采用 Layui `element.tabAdd` 实现多标签页管理，每个标签页内嵌独立 iframe，页面间状态互不干扰。
  - 标签栏样式定制：40px 高度标签标题栏，选中标签底部 2px 主题色下划线，关闭按钮悬浮红色高亮。
  - 首页（调度概览）不可关闭，其余标签均可关闭；关闭时自动切换至前一标签。
  - 标签切换时自动通知 iframe 暂停/恢复轮询（`pausePolling`/`resumePolling`），非激活标签不消耗轮询资源。
  - 标签切换时同步侧栏导航高亮，侧栏点击也会激活或创建对应标签。
  - Flex 布局确保 tab-content 自动填充剩余高度：`.tab-bar` 使用 `display:flex; flex-direction:column`，`.layui-tab-content` 使用 `flex:1` 自动撑满，iframe 高度 100% 精确匹配可用区域，不被底部固定 footer 遮挡。
- **主题切换控件**:
  - 顶部右侧采用药丸形状按钮（`border-radius: 16px`），内含太阳/月亮图标 + 文字标签（"亮色"/"暗色"），点击切换主题并通过 `localStorage` 持久化，同时通过 `iframe.contentWindow.onThemeChange()` 同步子页面主题与 ECharts 图表配色。
- **系统时钟**: 顶部右侧显示实时系统时间（`setInterval` 每秒更新），图标 + 时间文字水平居中。
- **左侧导航 (Sidebar) 定制**:
  - 摒弃了 Layui 默认的刺眼高亮色块。
  - 浅色模式下选中项呈现绿色透明底色 `rgba(16, 185, 129, 0.1)` + 绿色文字，悬停显示灰色底色。
  - 暗色模式下选中项呈现 `#25282C` 高级灰底色，带有 `8px` 圆角，左右边距悬浮设计，文字保持高对比度白色。
- **Layui 组件深度适配**:
  - **全局按钮**:
    - 主按钮：圆角 6px + 微光晕效果，悬停时轻微放大
    - 次要按钮：线性风格（透明背景 + 细边框），悬停时边框变绿
    - 危险按钮：暗色模式使用柔和红色 `#EF4343`，文字白色
    - 表格操作按钮：更新/删除纯文字显示，列宽 130px，更新按钮使用主题绿色背景
  - **表单与下拉框**: 修复了深色模式下 Input/Select 的背景透色，下拉列表 (dl/dd) 悬停与选中状态的主题色融合；浏览器自动填充时使用 `box-shadow: inset` 覆盖白色背景。
  - **日期选择器 (Laydate)**: 暗色模式下头部（年/月选择区域）改为暗黑底色 `#141517`（非默认的绿色），文字为白色，悬停显示主题绿；底部操作栏同步暗化；日期输入框禁用浏览器自动填充（`autocomplete="off"`）避免原生下拉框白色背景问题。
  - **数据表格与分页**: 表头背景、边框线透明度、Hover 行高亮、选中行背景色（`rgba(42, 219, 92, 0.15)`）、底部 Laypage 分页组件的当前页高亮色均已适配双主题。
  - **Switch 开关**: 开启状态使用 `--primary-color` 底色，暗色模式下开关内文字强制黑色，浅色模式下开关内文字为白色。
  - **弹窗 (Layer)**: 暗色模式下弹窗背景、标题栏、按钮区域全部适配深色面板色 `#1E2024`（比主界面背景 `#090A0B` 更浅，增强视觉层次区分），边框色 `rgba(255,255,255,0.1)`；确认按钮使用主题绿；关闭按钮使用 `filter: invert(1) brightness(2)` 反转背景图片精灵图颜色；弹窗添加 `border-radius: 8px` 圆角 + 双层阴影效果；遮罩层适配双主题（浅色 `rgba(0,0,0,0.3)` / 暗色 `rgba(0,0,0,0.5)`）。
- **滚动条隐藏**: 通过 CSS 隐藏浏览器原生滚动条（`::-webkit-scrollbar { display: none }` + `scrollbar-width: none`），支持 Chrome/Safari/Firefox/IE 全浏览器，保持滚动功能。
- **主题切换过渡动画**: 使用全局 `transition`（`*, *::before, *::after`）让所有元素的颜色属性（background-color、color、border-color、box-shadow）在主题切换时平滑过渡，过渡时长 0.3 秒。
- **状态徽章 (Status Badge)**:
  - 定义了 5 种柔和风格徽章（`.badge-soft-green/yellow/red/dark/gray`），采用低透明度背景 + 对应深色文字，在双主题下均有独立配色方案。其中 `badge-soft-dark`（紧急/EMERGENCY）使用深红色系（浅色 `#b91c1c` / 暗色 `#ff5252`），与告警红色形成层级区分。
  - 已应用于历史查询表格的状态列、详情弹窗建议排放表格的调度状态列、告警记录级别标签。

## 4. 下一步开发建议 (Next Steps)
当您在新的会话中恢复开发时，可以从以下几个方向着手：

1. **对接真实后端 API**:
   - 移除 `mock.js`，在 `charts.js` 和页面中引入 AJAX 请求，调用 Python FastAPI (或 Flask) 提供的 RESTful 接口。
2. **状态轮询机制**:
   - 在 Dashboard 中加入 `setInterval`，定期（如每 10 秒）向后端拉取最新的液位和告警数据，并动态更新 ECharts 实例 (`setOption`) 和表格数据。
3. **扩展页面功能**:
   - 增加告警历史专门统计页面等。
